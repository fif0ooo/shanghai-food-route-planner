# 上海觅食路线规划

## 项目简介

我是**东华大学旭日工商管理学院 信息管理与信息系统专业**的**赖思辰**。
这是我的本科毕业设计，题目是**《基于美食偏好的城市觅食路线规划小程序》**。  

本项目基于微信小程序实现，面向城市餐饮消费场景，结合用户的菜系偏好、预算范围、评分偏好与距离因素，对餐厅进行筛选与推荐，并生成个性化觅食路线。

## 产品 Demo 说明

本项目的产品 Demo 为微信小程序形式。  
由于当前**小程序体验版仍在上线审核中**，且微信小程序体验版需要加入**体验成员权限**后才可访问，因此目前暂时**无法提供可直接公开交互的在线体验链接**。

现阶段可先通过下方演示视频了解本项目的主要功能与交互流程，包括：
- 偏好设置
- 餐厅筛选与推荐
- 收藏与行程单管理
- 必去点设置
- 路线规划
- 地图展示与导航

后续若体验版审核完成，将补充正式体验方式。

## 功能亮点

- 基于用户偏好的餐厅推荐
- 支持按菜系、预算、评分、距离进行综合筛选
- 支持收藏餐厅与加入行程单
- 支持设置必去点并参与路线规划
- 支持生成多站点觅食路线
- 支持地图展示、路线可视化与导航

## Demo 简介

这是一个基于美食偏好的上海觅食路线规划小程序，可按菜系、预算、评分、距离筛选餐厅并生成个性化路线，支持收藏、行程单、必去点、地图展示与导航。
